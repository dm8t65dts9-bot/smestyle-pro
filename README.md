# NameStyle Pro

A free, responsive Bengali + English stylish name generator for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — mobile-friendly design
- `script.js` — name styles, categories, couple names and copy button

## Publish with GitHub Pages (iPhone or laptop)
1. Sign in at https://github.com/
2. Create a new **public** repository named `namestyle-pro` (or another name).
3. Upload `index.html`, `style.css`, and `script.js` from this ZIP. Upload the files themselves, not the ZIP.
4. Open the repository **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show the website URL in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/namestyle-pro/`

## Notes
- No API key, backend, or payment is required.
- Google Fonts is an optional online font import; the generator itself works without it.
- Some Unicode characters may not work in every social app or game.
